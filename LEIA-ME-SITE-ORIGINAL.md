# Site original cuidAÇÃO

A pasta site/ contém a primeira versão funcional do site, anterior à integração
com o módulo do Perequê. Mantém o design verde, configurações de aparência,
acessibilidade e interações locais. Agendamentos e denúncias são demonstrações
salvas neste navegador, sem envio a órgãos públicos.

Para abrir com um servidor estático: `python -m http.server 4173 --directory site`.
Depois acesse http://localhost:4173. As bibliotecas e os mapas precisam de internet.
O código original do projeto CuidAcao continua na raiz desta branch.
